# Амплитуда 95 — обновление первой и второй главы

В архиве находится готовый `index.html` для замены текущего файла в репозитории `raretrickster/a95`. URL сайта и Telegram-бот не меняются.

## Что добавлено
- локальное сохранение прогресса после каждого выбора через `localStorage`;
- резервная совместимость со старым `sessionStorage`;
- попытка синхронизации прохождения через `Telegram.WebApp.CloudStorage` внутри Telegram;
- журнал выбранных вариантов и сюжетные флаги;
- подтверждение перед сбросом истории;
- редкие авторские пометки после выбранных ключевых решений;
- интерактивная глава II: сентябрь, школа, знакомство с Ёжом, плохое состояние на пикнике и помощь Арины;
- отложенные фразы в зависимости от ранних решений.

## Установка с Android
1. Скачай ZIP и распакуй его либо скачай отдельный `index.html`.
2. Открой `https://github.com/raretrickster/a95` в браузере.
3. Открой существующий `index.html` и выбери Edit — при желании сохрани старую версию локально.
4. Замени содержимое файла новым `index.html` из архива и нажми Commit changes.
5. Дождись публикации в Netlify, затем проверь продолжение с сохранённой сцены.

Обработчик `netlify/functions/telegram-start.mjs` не изменён. Не вставляй токен бота в HTML/JavaScript или GitHub.

## Важное о сохранениях
Локальное сохранение работает в том же браузерном хранилище. В Telegram Mini App код также использует CloudStorage, если Telegram-клиент поддерживает его. Поэтому сначала проверь сохранение на одном устройстве; облачная синхронизация зависит от поддержки API клиентом Telegram.
