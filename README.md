# Амплитуда 95 — MVP 001

Статический прототип интерактивной истории на русском языке. Работает без сборки и сервера.

## Быстрый запуск
1. Откройте `index.html` в браузере для локального теста.
2. Для публикации загрузите `index.html` в отдельный GitHub-репозиторий.
3. В Netlify выберите Add new project → Import an existing project, подключите репозиторий.
4. Для обычного статического HTML оставьте build command пустым, а publish directory укажите `.` (корень репозитория), если Netlify не определил его автоматически.
5. После публикации откройте HTTPS-ссылку на телефоне.
6. В Telegram через @BotFather создайте отдельного бота и задайте HTTPS-ссылку через `/setmenubutton`.

## Что уже работает
- Адаптивная мобильная вёрстка
- Несколько веток истории
- Выборы и различные финальные состояния
- Кнопка повторного прохождения
- Минимальная анимация переходов
- Прогресс сцены и локальная история выбора в `sessionStorage`

## Важно
Это оригинальный черновой эпизод для проверки механики, а не дословная адаптация книги. Перед публичным запуском заменить текст на утверждённый автором материал, проверить орфографию и визуально протестировать в Telegram Android.
