# Амплитуда 95 — интерактивный MVP 001

Адаптация начала Части I книги «Амплитуда 95» Миши Цыгановского. Эпизод следует каноническим событиям: подготовка к поездке, Москва, поезд до Анапы, гостевой дом в Витязево, путь к морю, решение уехать через пять дней, возвращение домой и смерть собаки. Выборы меняют фокус воспоминаний и внутреннюю реакцию рассказчика, а не переписывают основные события книги.

## Локальный запуск
Откройте `index.html` в браузере. Сборка и сервер не требуются.

## Публикация через Netlify
1. Загрузите `index.html` и `README.md` в корень отдельного GitHub-репозитория.
2. В Netlify выберите Add new project → Import an existing project и подключите репозиторий.
3. Для простого статического HTML команда сборки не нужна; каталог публикации — корень репозитория (`.`), если Netlify не распознал его автоматически.
4. Откройте опубликованный HTTPS-адрес и протестируйте все ветки на телефоне.
5. В Telegram через @BotFather создайте отдельного бота и назначьте кнопку меню Mini App на HTTPS-адрес сайта.

## Что работает
- Адаптивный мобильный интерфейс с киношной цветовой атмосферой и зерном.
- 10+ сцен с несколькими выборами и сюжетными фокусами.
- Концовка эпизода и повторное прохождение.
- Сохранение текущего прогресса в `sessionStorage`.
- Поддержка базовой интеграции Telegram Web Apps (`ready`, `expand`).
- Кнопка поделиться в конце эпизода.

## Примечание
Это первый адаптированный эпизод, а не вся книга. Выборы строятся вокруг фокуса памяти; основные события эпизода остаются каноническими. Перед публичным запуском автор может отредактировать формулировки, фактические детали и глубину ветвления.
